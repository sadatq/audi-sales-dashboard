# Audi Sales Dashboard

By Quazi Sahariar Sadat

An interactive automotive sales portfolio dashboard with a cherry and maroon theme, model-specific car images, year and location filters, KPI cards, sales trends, and model comparisons.

## Run locally

Download this repository and open `index.html` in a browser. The dashboard is built with HTML, CSS, and JavaScript. Car images are embedded in the file.

## Data and attribution

This project uses demonstration data for educational and portfolio purposes. It does not represent official Audi sales statistics and is not affiliated with Audi. Audi names and trademarks belong to their respective owners. The dashboard and visual assets were developed with AI assistance.

## Publish with GitHub Pages

In repository Settings, select Pages. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
