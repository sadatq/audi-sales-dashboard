# Inter Miami Performance Lab

By Quazi Sahariar Sadat

[Open dashboard](https://sadatq.github.io/audi-sales-dashboard/inter-miami/)

The original pink, teal and navy dashboard, built with React, TypeScript and Recharts. Includes competition and venue filters, match performance metrics, player contributions and CSV import/export.

This GitHub Pages edition uses demonstration data and browser local storage for CSV imports. GitHub Pages does not run the original SQL backend. The original React application, REST API and demonstration dataset are preserved under original-source. The original API uses Cloudflare D1 (SQLite).

These are educational demonstration statistics, not official or live Inter Miami data. This project is not affiliated with Inter Miami CF.
